# Larson Family Maps

A trip planner for the Larson family, in the spirit of Google My Maps.

**Open the site:** https://jdl2025.github.io/FamilyMaps/

## How it works

1. **Pins** – drop every place you might want to see. Name them, add notes and links, and pick an icon and color.
2. **Route** – connect the dots in the order you'll visit them. Each drive shows miles and driving time.
3. **Days** – choose where each day ends, then download a day-by-day trip plan as a Word file.

Also: a measure tool, Google My Maps import (KML/KMZ), KML export, and backup/restore.

## Good to know

- Trips are saved in the browser on each device. Use **☰ → Download a backup** now and then.
- Map tiles: Esri and OpenTopoMap. Directions: Valhalla (FOSSGIS) with OSRM as a backup. Search: Photon and Nominatim. All are free and need no account or key.
- The whole site is one file: `index.html`.
